Hello, Dolly — desktop widgets
================================

You already have Python and Pillow. You do not need to install anything else.

RUN THIS
  Double-click  start-widgets.bat

Two companions appear right away — frameless, always on top:
  Dolly     guitar loop
  Fastback  dark-green '67 doing donuts with tire smoke

Drag either onto any window or any monitor.

CONTROLS
  Left-drag     move (any screen)
  Right-click   Dolly: switch look / Fastback: close
  Double-click  close that widget
  Esc           close that widget

The small HELLO, DOLLY panel can also spawn a clock, sticky note, or quotes.
Quit all closes everything.

Positions are remembered next time (saved under AppData\Local\HelloDolly).

IF NOTHING APPEARS
  1. Do not run pip again — Pillow is already installed.
  2. Double-click start-widgets.bat  (not the .py file).
  3. If a black window flashes, run start-widgets.bat again and read the message.
