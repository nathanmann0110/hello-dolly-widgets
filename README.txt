Hello, Dolly — desktop companions
=================================

Three frameless always-on-top companions:
  Dolly     guitar loop
  Fastback  black '67 — slow 360 donut, 24fps, headlights + electric rear smoke
  Van       Fusion Transit — same slow 360, lights, electric rear smoke

Drag to any monitor. Smoke stays on the rear tires as they spin.

RUN THIS
  Double-click  start-widgets.bat

CONTROLS
  Left-drag     move (any screen)
  Right-click   close that companion
  Double-click  close
  Esc           close
