Hello, Dolly — desktop companions
=================================

Three frameless always-on-top companions:
  Dolly     guitar loop
  Fastback  black '67 doing donuts
  Van       Fusion Audio+Video Transit doing donuts

Clock and sticky notes are gone. This pack is just those three.

RUN THIS
  Double-click  start-widgets.bat

CONTROLS
  Left-drag     move (any screen)
  Right-click   close that companion
  Double-click  close
  Esc           close

The small HELLO, DOLLY panel can respawn Dolly, Fastback, or Van.
Quit all closes everything.

IF NOTHING APPEARS
  Double-click start-widgets.bat (not the .py file).
